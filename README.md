# WorkMonitor

Teamsから出力した稼働環境一覧を解析し、
Excelファイルへ日次履歴として保存するツールです。

## 概要

入力テキストファイルから
- 拠点
- 環境名
を取得し、
`WorkList.xlsx`
へ日付単位のシートを作成します。
さらに前日データと比較して、
- 初回稼働日
- 連続稼働日数
を自動計算します。

## 入力ファイル

### teams_yyyymmdd.txt

例

2025年09月02日 稼働環境一覧
東京 環境A
大阪 環境B
名古屋 環境C

形式

日付
拠点 環境名
拠点 環境名
・・・

## 出力ファイル

### WorkList.xlsx

作成されるシート例

input 20250902 20250901 20250831

### 日付シート構成

|列|内容       |
|--|-----------|
|A |日付       |
|B |拠点       |
|C |環境名     |
|D |開始日     |
|E |連続稼働日数|

例

|日付    |拠点 |環境名|開始日   |連続稼働日数|
|--------|----|------|--------|-----------|
|20250902|東京|環境A  |20250901|          2|
|20250902|大阪|環境B  |20250902|          1|

---

## 動作仕様

### 新規環境

前日のシートに存在しない場合

- 開始日 = 当日
- 連続稼働日数 = 1

### 継続環境

前日のシートに存在する場合

- 開始日を引き継ぐ
- 連続稼働日数を +1

---

## アラート判定

連続稼働日数が3日以上の環境を集計します。

実行結果例

処理日: 20250902 
前日シート発見: 20250901
WorkList.xlsx 更新完了 
シート名 : 20250902 
件数 : 12 
3日以上連続稼働: 4件
